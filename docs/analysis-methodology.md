# Методика анализа прибыльности

## Выбор источника

1. Просматриваются видимые листы в порядке, указанном в книге.
2. Если найден объект структурированной Excel-таблицы (`Table`), берётся первый такой объект по порядку листов и таблиц.
3. Если структурированных таблиц нет, берётся используемый диапазон первого непустого видимого листа.
4. Для выбранного диапазона приложение сначала пытается распознать **отчёт о прибыли** (статьи по строкам, периоды по столбцам). Если структура не похожа на отчёт, включается **построчный режим** таблицы продаж.

Файл читается в памяти, не сохраняется на диск и не передаётся во внешнюю систему. Допускаются книги `.xlsx` и `.xlsm` до 50 МиБ; размер распакованной книги, ширина/высота диапазона и число непустых ячеек ограничены защитными лимитами. Парсер использует сохранённые в XLSX cached values для ячеек с формулами — формулы не пересчитываются.

## Режим отчёта о прибыли

### Распознавание структуры

Режим включается, если одновременно выполняются условия:

- в одной из первых 30 строк найдена шапка с минимум двумя столбцами значений, у которых есть текстовые заголовки (например, `1кв`, `2кв`, `Итого`);
- слева от этих столбцов есть колонка статей, где распознано не менее трёх профильных строк;
- среди статей есть выручка и хотя бы одна строка себестоимости или затрат;
- в столбцах значений есть числовые данные (минимум по две ячейки на столбец).

Строка данных не принимается за шапку: заголовки столбцов значений должны содержать буквы или быть четырехзначным годом. Это защищает от ситуации, когда первая строка с числами ошибочно считается шапкой.

Итоговый столбец ищется по заголовку `Итого`, `Всего`, `Total` или `Grand total`. Если его нет, суммы рассчитываются как сумма периодов, а приложение выводит предупреждение. Если итог расходится с суммой периодов более чем на 1 денежную единицу, также выводится предупреждение.

### Распознавание статей

Сопоставление нечувствительно к регистру; кириллическая `ё` нормализуется в `е`. Проверки идут в порядке приоритета:

| Роль | Примеры заголовков |
| --- | --- |
| Чистая прибыль | `Чистая прибыль`, `Net profit`, `Net income` |
| Налог на прибыль | `Налог на прибыль`, `Income tax`, `Profit tax` |
| НДС к уплате (справочно) | `Налог НДС`, `НДС к уплате`, `VAT payable` |
| Входящий НДС (справочно) | `Входящий НДС`, `Input VAT`, `НДС к вычету` |
| Начисленный НДС, итог | `Итого НДС`, `Всего НДС`, `Total VAT` |
| Начисленный НДС, компонент | `НДС Выручка...`, `НДС Реализация...`, `Output VAT` |
| Себестоимость | `Себестоимость реализация`, `COGS`, `Cost of goods` |
| Себестоимость, итог | `Итого себестоимость`, `Total cost` |
| Затраты | `Себестоимость затрат`, `Расходы`, `OPEX` |
| Затраты, итог | `Итого расходы`, `Всего затрат`, `Total expenses` |
| Выручка, итог | `Итого выручка`, `Всего выручка`, `Total revenue` |
| Выручка, компонент | `Выручка по отчетам ККМ`, `Реализация (Накладные)` |
| Прибыль до налога | `Прибыль`, `Прибыль до налогообложения`, `Profit before tax` |

Особенности:

- Строки с `без НДС` не используются как выручка или НДС, чтобы не сложить повторно компоненты, уже входящие в итог.
- Строки `Вычет по товарам без НДС` и `Товары реализация без НДС` считаются справочными и не участвуют в расчёте прибыли.
- Если найдена итоговая строка выручки, компоненты выручки не суммируются. Аналогично для себестоимости, затрат и начисленного НДС.
- Если итоговых строк несколько, их значения складываются, а приложение выводит предупреждение.
- `НДС к уплате` и `Входящий НДС` показываются справочно и не уменьшают прибыль.

### Формулы

1. **Выручка без НДС** = итоговая выручка − начисленный НДС (если строка начисленного НДС найдена). Если строка не найдена, выручка используется как есть, а приложение выводит предупреждение.
2. **Себестоимость и затраты** = себестоимость + операционные затраты. Если есть итоговые строки, используются только они.
3. **Прибыль до налога на прибыль** = выручка без НДС − себестоимость и затраты.
4. **Налог на прибыль** = значение строки налога на прибыль. Если строка не найдена, чистая прибыль не рассчитывается.
5. **Чистая прибыль** = прибыль до налога − налог на прибыль. Если в книге есть явная строка `Чистая прибыль`, используется она; расхождение с расчётом выводится как предупреждение.
6. **Маржинальность** = прибыль до налога ÷ выручка без НДС × 100.
7. **Чистая маржинальность** = чистая прибыль ÷ выручка без НДС × 100.
8. **НДС к уплате** = справочная строка книги; не вычитается из прибыли, поскольку это расчёт с бюджетом, а не расход периода.
9. Если явная строка `Прибыль до налога` есть, она сверяется с расчётом по выручке и затратам; при расхождении более чем на 1% или 1 денежную единицу (что больше) выводится предупреждение, а в итог берётся расчёт по выручке и затратам.
10. Периоды рассчитываются по тем же правилам отдельно для каждого столбца. Полностью нулевой период сопровождается предупреждением о возможном отсутствии данных.

Себестоимость и затраты принимаются как суммы без НДС: входящий НДС в книге ведётся отдельно. Если затраты включают входящий НДС, прибыль может быть занижена; приложение выводит соответствующее предупреждение. Это управленческая оценка, а не бухгалтерская или налоговая отчётность.

## Построчный режим таблицы продаж

### Распознавание заголовков

Для обычного диапазона кандидатом заголовков становится строка с распознаваемым финансовым столбцом; поиск идёт в первых 25 строках. Для структурированной таблицы заголовком считается первая строка диапазона, как предписывает Excel Table.

| Роль | Примеры заголовков |
| --- | --- |
| Выручка / продажи | `Выручка`, `Сумма продаж`, `Реализация`, `Revenue`, `Sales`, `Turnover`, `Amount` |
| Выручка за единицу | `Цена продажи`, `Цена реализации`, `Selling price`, `Unit price`, `за единицу` |
| Себестоимость | `Себестоимость`, `Закупка`, `Затраты`, `Расходы`, `COGS`, `Cost` |
| Себестоимость за единицу | `Цена закупки`, `Закупочная цена`, `Unit cost`, `cost per unit` |
| Прибыль | `Прибыль`, `Profit`, `Gross profit`, `Net income` |
| Прибыль за единицу | заголовок прибыли вместе с `за единицу`, `за шт.`, `per unit` |
| Процент маржи | `Маржа, %`, `Маржинальность`, `Рентабельность`, `Margin %` |
| Количество | `Количество`, `шт.`, `Qty`, `Quantity`, `Units sold` |
| Позиция | `Товар`, `Номенклатура`, `Наименование`, `Артикул`, `Product`, `Item`, `SKU` |

Строки `Итого`, `Итог`, `Всего`, `Total`, `Grand total` исключаются из суммирования в построчном режиме, чтобы не складывать итог повторно.

### Формулы

Приоритет расчёта по каждой строке:

1. **Прибыль:** готовый числовой столбец прибыли; иначе прибыль за единицу × количество; иначе выручка − себестоимость; иначе выручка × указанный процент маржи / 100.
2. **Выручка:** сумма выручки; иначе цена продажи за единицу × количество. Если количество не найдено, для цены за единицу условно используется 1.
3. **Себестоимость:** готовая сумма себестоимости; иначе закупочная цена за единицу × количество. Если одновременно есть выручка и прибыль, но нет себестоимости, используется выручка − прибыль.
4. Если есть себестоимость и прибыль, но нет выручки, используется себестоимость + прибыль.
5. **Общая маржинальность:** сумма прибыли / сумма выручки × 100, только для строк, где обе величины доступны.

Если есть и прямой столбец прибыли, и одновременно выручка с себестоимостью, отчёт использует прямой столбец прибыли; заметное расхождение с `выручка − себестоимость` выводится как предупреждение.

## Числа и ограничения

- Поддерживаются десятичная запятая или точка, пробелы-разделители тысяч, знак минуса, скобки для отрицательных значений и распространённые денежные суффиксы.
- Excel-значения в формате процентов могут храниться как дроби (`0,25` = 25%). При заголовке процентного столбца такие дроби масштабируются; буквальный символ `%` повторно не масштабируется.
- Валюта автоматически не определяется и не конвертируется. Числа показываются без знака валюты.
- Прибыль/затраты могут включать или не включать налоги, логистику, скидки, возвраты, комиссии и постоянные расходы — это зависит от исходной таблицы. Приложение не делает предположений о бухгалтерском смысле данных.
- Автоматическое распознавание заголовков и статей эвристическое. Пользователь должен проверить блок «Как прочитана таблица» и предупреждения перед использованием итогов.
- Старый формат `.xls`, `.xlsb`, сводные отчёты с нестандартной структурой, внешние ссылки и пересчёт формул пока не поддерживаются.
- В режиме отчёта заголовки периодов должны быть текстовыми (`1кв`, `Январь`, `Q1 2025`) или четырехзначным годом. Числовые заголовки без букв (например, `01.2025`) не распознаются как периоды.
- Строки с `без НДС` в режиме отчёта игнорируются, чтобы избежать двойного счёта; это ограничение можно расширить при появлении новых форматов книг.
