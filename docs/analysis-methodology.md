# Методика анализа прибыльности

## Выбор источника

1. Просматриваются видимые листы в порядке, указанном в книге.
2. Если найден объект структурированной Excel-таблицы (`Table`), берётся первый такой объект по порядку листов и таблиц.
3. Если структурированных таблиц нет, берётся используемый диапазон первого непустого видимого листа. Для него поиск заголовков выполняется в первых 25 строках.
4. Строки `Итого`, `Итог`, `Всего`, `Total`, `Grand total` исключаются из суммирования, когда метка распознана в столбце товара или в первом непустом поле.

Файл читается в памяти, не сохраняется на диск и не передаётся во внешнюю систему. Допускаются книги `.xlsx` и `.xlsm` до 50 МиБ; размер распакованной книги, ширина/высота диапазона и число непустых ячеек ограничены защитными лимитами. Парсер использует сохранённые в XLSX cached values для ячеек с формулами — формулы не пересчитываются.

## Распознавание заголовков

Сопоставление нечувствительно к регистру; кириллическая `ё` нормализуется в `е`. Обрабатываются наиболее распространённые русские и английские обозначения:

| Роль | Примеры заголовков |
| --- | --- |
| Выручка / продажи | `Выручка`, `Сумма продаж`, `Реализация`, `Revenue`, `Sales`, `Turnover`, `Amount` |
| Выручка за единицу | `Цена продажи`, `Цена реализации`, `Selling price`, `Unit price`, `за единицу` |
| Себестоимость | `Себестоимость`, `Закупка`, `Затраты`, `Расходы`, `COGS`, `Cost` |
| Себестоимость за единицу | `Цена закупки`, `Закупочная цена`, `Unit cost`, `cost per unit` |
| Прибыль | `Прибыль`, `Profit`, `Gross profit`, `Net income` |
| Прибыль за единицу | заголовок прибыли вместе с `за единицу`, `за шт.`, `per unit` |
| Процент маржи | `Маржа, %`, `Маржинальность`, `Рентабельность`, `Margin %` |
| Количество | `Количество`, `шт.`, `Qty`, `Quantity`, `Units sold` |
| Позиция | `Товар`, `Номенклатура`, `Наименование`, `Артикул`, `Product`, `Item`, `SKU` |

Для обычного диапазона кандидатом заголовков становится строка с распознаваемым финансовым столбцом. Для структурированной таблицы заголовком считается первая строка диапазона, как предписывает Excel Table.

## Формулы

Приоритет расчёта по каждой строке:

1. **Прибыль:** готовый числовой столбец прибыли; иначе прибыль за единицу × количество; иначе выручка − себестоимость; иначе выручка × указанный процент маржи / 100.
2. **Выручка:** сумма выручки; иначе цена продажи за единицу × количество. Если количество не найдено, для цены за единицу условно используется 1.
3. **Себестоимость:** готовая сумма себестоимости; иначе закупочная цена за единицу × количество. Если одновременно есть выручка и прибыль, но нет себестоимости, используется выручка − прибыль.
4. Если есть себестоимость и прибыль, но нет выручки, используется себестоимость + прибыль.
5. **Общая маржинальность:** сумма прибыли / сумма выручки × 100, только для строк, где обе величины доступны.

Если есть и прямой столбец прибыли, и одновременно выручка с себестоимостью, отчёт использует прямой столбец прибыли; заметное расхождение с `выручка − себестоимость` выводится как предупреждение.

## Числа и ограничения

- Поддерживаются десятичная запятая или точка, пробелы-разделители тысяч, знак минуса, скобки для отрицательных значений и распространённые денежные суффиксы.
- Excel-значения в формате процентов могут храниться как дроби (`0,25` = 25%). При заголовке процентного столбца такие дроби масштабируются; буквальный символ `%` повторно не масштабируется.
- Валюта автоматически не определяется и не конвертируется. Числа показываются без знака валюты.
- Прибыль/затраты могут включать или не включать налоги, логистику, скидки, возвраты, комиссии и постоянные расходы — это зависит от исходной таблицы. Приложение не делает предположений о бухгалтерском смысле данных.
- Автоматическое распознавание заголовков эвристическое. Пользователь должен проверить блок «Как прочитана таблица» и предупреждения перед использованием итогов.
- Старый формат `.xls`, `.xlsb`, сводные отчёты с нестандартной структурой, внешние ссылки и пересчёт формул пока не поддерживаются.
