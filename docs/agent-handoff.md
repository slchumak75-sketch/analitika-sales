## Архитектура

- `cmd/analitika-sales/main.go` — точка входа, локальный loopback HTTP-сервер на свободном порту и открытие браузера.
- `internal/app/server.go` — локальный HTTP API, загрузка файла, лимиты и security headers.
- `internal/app/web/index.html` — автономный HTML/CSS/JS интерфейс, внедряемый в executable директивой `go:embed`. В режиме отчёта показывает структуру отчёта, разбивку по периодам и отдельные метрики.
- `internal/xlsx/reader.go` — чтение OOXML из ZIP стандартной библиотекой Go; таблицы Excel, relationships, shared strings, inline strings, кешированные результаты формул.
- `internal/analysis/analyze.go` — точка входа `Analyze`, построчный режим, распознавание заголовков, числовой парсер, расчёты и предупреждения.
- `internal/analysis/report.go` — режим отчёта о прибыли: определение структуры, роли статей, выбор итогового столбца, расчёт периодов, чистой прибыли и предупреждений.
- `internal/analysis/*_test.go` — модульные тесты, включая регрессию на реальной книге.
- `internal/app/server_test.go` — HTTP-тесты, включая сквозную загрузку реальной книги.
- `.github/workflows/build-windows.yml` — Windows x64 runner, `go test ./...`, сборка GUI executable и artifact `AnalitikaSales-windows-amd64`.

## Что сделано в этой сессии

1. Найдена и разобрана книга `ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xlsx`.
2. Определено, что это отчёт о прибыли с кварталами `D:G` и итогом `H`, а не таблица SKU.

   - маржинальность и чистая маржинальность;
   - разбивка по периодам и проверка итог vs сумма периодов;

## Допущения и известные нюансы

- Себестоимость и затраты приняты как суммы без НДС. Входящий НДС в книге ведётся отдельно; если затраты включают НДС, прибыль может быть занижена.
- `Инвест. вычет` 11 733,32 включён книгой в `Себестоимость затрат`; нужно подтвердить, является ли он расходом периода.
- 4кв полностью нулевой; годовые итоги покрывают 1–3 кварталы.
- Нет детализации по товарам, поэтому лучшие/худшие SKU по этой книге не рассчитаны.
- Формулы не пересчитываются; используются cached values.
- Режим отчёта эвристический: шапка периодов должна быть текстовой или четырехзначным годом; числовые заголовки вроде `01.2025` пока не распознаются.
- `НДС к уплате` не вычитается из прибыли; это расчёт с бюджетом.
