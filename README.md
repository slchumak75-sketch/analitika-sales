# Аналитика продаж

Локальное приложение на Go с HTML-интерфейсом для анализа прибыльности первой таблицы книги Excel. Запускается как Windows-программа и открывает интерфейс в браузере по умолчанию. Исходная книга обрабатывается на компьютере пользователя и не отправляется на сервер.

## Исходная книга

В репозитории находится `ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xlsx` — агрегированный отчёт о прибыли `МИРСТРОЙМАРКЕТ` за 1–3 кварталы (лист `Лист1`, диапазон `B2:H45`). Это не построчная таблица продаж: статьи отчёта расположены по строкам, кварталы — по столбцам `D:H`. Приложение распознаёт такую структуру и показывает прибыль, налоги и разбивку по периодам.

Краткий итог по книге:

| Показатель | Сумма |
| --- | ---: |
| Выручка без НДС | 1 228 127,51 |
| Себестоимость и затраты | 1 111 424,21 |
| Прибыль до налога на прибыль | 116 703,30 |
| Налог на прибыль | 23 340,66 |
| Чистая прибыль | 93 362,64 |
| Маржинальность | 9,50% |
| Чистая маржинальность | 7,60% |
| НДС к уплате (справочно) | 57 001,75 |

Подробный разбор, квартальная динамика и структура затрат — в [`docs/mir-report.md`](docs/mir-report.md). Допущения и ограничения — в [`docs/source-workbook-status.md`](docs/source-workbook-status.md).

## Возможности

- Открыть книгу `.xlsx` или `.xlsm` и автоматически выбрать первую структурированную Excel-таблицу. Если формальных таблиц в книге нет — взять используемый диапазон первого непустого видимого листа.
- Распознать два типа данных:
  - **построчную таблицу продаж** — товар, выручка, себестоимость, прибыль, количество;
  - **отчёт о прибыли** — статьи в одном столбце, периоды в соседних, итоговый столбец `Итого`.
- В режиме отчёта о прибыли:
  - найти строки выручки, начисленного НДС, себестоимости, затрат, налога на прибыль и чистой прибыли;
  - рассчитать выручку без НДС, прибыль до налога, чистую прибыль и маржинальность;
  - показать структуру отчёта и разбивку по кварталам/периодам;
  - показать НДС к уплате справочно, не вычитая его из прибыли;
  - проверить, что итоговый столбец совпадает с суммой периодов.
- В построчном режиме рассчитать выручку, себестоимость, прибыль и маржинальность, определить убыточные строки и показать до пяти лучших и худших позиций.
- Поддержать цену продажи/закупки и прибыль за единицу при наличии столбца количества.
- Исключить строку `Итого` / `Total` в построчном режиме, чтобы не складывать итог повторно.
- Показать найденные соответствия столбцов и предупреждения о неполных данных, неоднозначном расчёте и особенностях формул.

Поддерживаются `.xlsx` и `.xlsm`. Старый бинарный формат `.xls`, файлы `.xlsb` и внешние связи не поддерживаются. Формулы Excel берутся из сохранённых в книге результатов; перед загрузкой пересчитайте и сохраните книгу в Excel, если формулы изменялись.

## Запуск в Windows

1. Откройте **GitHub → Actions → Build Windows application**.
2. Выберите последний успешный запуск workflow и скачайте artifact **`AnalitikaSales-windows-amd64`**.
3. Распакуйте архив и запустите `AnalitikaSales-windows-amd64.exe`. Приложение откроет HTML-интерфейс в браузере.
4. Перетащите Excel-файл в окно или выберите его через диалог, затем нажмите **«Анализировать таблицу»**.
5. Кнопка **«Завершить»** останавливает локальное приложение.

Приложение слушает случайный свободный порт только на `127.0.0.1`; загрузка ограничена 50 МиБ. Внешние веб-ресурсы и сторонние сервисы не используются.

## Сборка и тесты для разработчика

Нужен Go 1.22 или новее:

```sh
go test ./...
go run ./cmd/analitika-sales
```

При запуске автоматически открывается браузер. Для разработки без автоматического открытия (URL будет выведен в консоль):

```sh
go run ./cmd/analitika-sales -no-browser
```

Чтобы собрать Windows x64 executable вручную на Windows:

```powershell
New-Item -ItemType Directory -Force dist | Out-Null
go build -trimpath -ldflags="-s -w -H=windowsgui" -o dist/AnalitikaSales-windows-amd64.exe ./cmd/analitika-sales
```

Проект не использует сторонние Go-модули: чтение XLSX реализовано стандартной библиотекой Go. Тесты включают регрессию на реальной книге `ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xlsx` и сквозную проверку загрузки через локальный HTTP-интерфейс.

## GitHub Actions

Workflow `.github/workflows/build-windows.yml` автоматически запускается при push в `main` или `arena/**`, при pull request в `main` и вручную через `workflow_dispatch`. Он выполняет `go test ./...`, собирает Windows x64 `.exe` и публикует его как artifact на 30 дней. Ветка текущей сессии `arena/bb139722-analitika-sales` входит в `arena/**`.

## Как считается прибыльность

### Отчёт о прибыли

1. **Выручка без НДС** = итоговая выручка − начисленный НДС (`Итого НДС` / `НДС начисленный`).
2. **Себестоимость и затраты** = строки себестоимости (COGS) + строки операционных затрат. Если есть итоговая строка, используются только итоговые строки, чтобы не сложить компоненты дважды.
3. **Прибыль до налога на прибыль** = выручка без НДС − себестоимость и затраты.
4. **Налог на прибыль** берётся из одноимённой строки отчёта.
5. **Чистая прибыль** = прибыль до налога − налог на прибыль; если в книге есть явная строка `Чистая прибыль`, используется она.
6. **Маржинальность** = прибыль до налога ÷ выручка без НДС × 100. **Чистая маржинальность** = чистая прибыль ÷ выручка без НДС × 100.
7. **НДС к уплате** показывается справочно: это расчёт с бюджетом, а не расход периода, поэтому он не вычитается из прибыли.
8. Если итоговый столбец `Итого` не найден, суммы рассчитываются по периодам. Если итог расходится с суммой периодов более чем на 1, выводится предупреждение.

Себестоимость и затраты принимаются как суммы без НДС: входящий НДС в типовых книгах ведётся отдельно. Если затраты включают НДС, прибыль может быть занижена — приложение выводит предупреждение. Это управленческая оценка, а не бухгалтерская или налоговая отчётность.

### Построчная таблица продаж

1. Если распознан столбец **прибыли**, используется его сумма.
2. Иначе при наличии выручки и себестоимости считается `прибыль = выручка − себестоимость`.
3. Если есть выручка и столбец процента маржи — `прибыль = выручка × маржа / 100`.
4. Если отсутствуют выручка или себестоимость, но есть прибыль, недостающее значение может быть выведено из `выручка = себестоимость + прибыль` или `себестоимость = выручка − прибыль`.
5. Итоговая маржинальность рассчитывается как `прибыль / выручка × 100` по строкам, где найдены обе величины.

Названия столбцов и ограничения автоматического сопоставления описаны в [`docs/analysis-methodology.md`](docs/analysis-methodology.md).

## Ограничения

- `.xls`, `.xlsb`, внешние связи и пересчёт формул не поддерживаются.
- Автоматическое распознавание заголовков и статей эвристическое; проверяйте блок «Как прочитана таблица» и предупреждения.
- Валюта не определяется и не конвертируется.
- В отчёте `МИРСТРОЙМАРКЕТ` не заполнен 4кв, поэтому годовые итоги фактически покрывают три квартала; подробности — в [`docs/source-workbook-status.md`](docs/source-workbook-status.md).
