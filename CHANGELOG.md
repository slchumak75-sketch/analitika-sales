# Журнал изменений

## Unreleased — 2026-10-19

### Анализ продаж по PDF-ведомости

- Добавлен парсер PDF-ведомости 1С (`tools/parse_vedomost.py`): восстановление 111 строк из разнесённых по страницам колонок, сверка баланса остатков.
- Добавлен расчётный слой (`tools/build_analysis.py`): литровый эквивалент, ABC по литрам, XYZ по сезонной вариации, покрытие, статусы остатков, дефицит/профицит, качество данных.
- Подготовлен аналитический отчёт `reports/analiz-prodazh-2025-10_2026-10.md` и автономный дашборд `reports/dashboard.html` без внешних зависимостей.
- Выгружены разобранные данные `reports/vedomost_2025-10_2026-10.csv` и агрегаты `reports/summary.json`.
- Зафиксированы ограничения: в ведомости нет цен (выручка и прибыль не считаются), месячные колонки расходятся с «Расходом» на 16,5%, объём в литрах — расчётный.
- Дашборд проверен в headless Chromium на 1440/1024/390 px и адаптирован под мобильные экраны; добавлен `tools/serve_report.py` для локального просмотра.

### Приложение

- Зафиксировано отсутствие книги Excel в исходном репозитории; реальные финансовые итоги не придуманы.
- Добавлено локальное приложение на Go с автономным HTML/CSS/JS GUI и анализом первой Excel-таблицы.
- Добавлены XLSX/XLSM-парсер на стандартной библиотеке, эвристическое сопоставление столбцов и расчёт выручки, себестоимости, прибыли и маржинальности.
- Добавлены предупреждения, список лучших/убыточных позиций, лимиты загрузки и обработка только на локальном компьютере.
- Добавлены модульные тесты и GitHub Actions workflow для тестирования и сборки Windows x64 executable.
- Добавлена документация по методике, статусу исходных данных и продолжению работы агентом.
