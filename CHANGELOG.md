# Журнал изменений

## Unreleased — 2026-10-19

- Зафиксировано отсутствие книги Excel в исходном репозитории; реальные финансовые итоги не придуманы.
- Добавлено локальное приложение на Go с автономным HTML/CSS/JS GUI и анализом первой Excel-таблицы.
- Добавлены XLSX/XLSM-парсер на стандартной библиотеке, эвристическое сопоставление столбцов и расчёт выручки, себестоимости, прибыли и маржинальности.
- Добавлены предупреждения, список лучших/убыточных позиций, лимиты загрузки и обработка только на локальном компьютере.
- Добавлены модульные тесты и GitHub Actions workflow для тестирования и сборки Windows x64 executable.
- Добавлена документация по методике, статусу исходных данных и продолжению работы агентом.
